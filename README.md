# Damask Shop - Каталог вейп-магазина

Русифицированный сайт-каталог вейп-магазина Damask Shop с расширенными возможностями интерактивного просмотра и управления контентом.

## Технологический стек

- Frontend: React + Vite
- Backend: Express.js
- Database: PostgreSQL с Drizzle ORM
- Стили: Tailwind CSS
- Типизация: TypeScript

## Функциональность

- Каталог товаров с фильтрацией по категориям и поиском
- Страница новостей и акций
- Страница с расположением и контактами магазинов
- Админ-панель для управления контентом (товары, новости, магазины, настройки)
- Аутентификация администратора
- Адаптивный дизайн для мобильных и десктопных устройств

## Локальный запуск

1. Установите зависимости:
   ```
   npm install
   ```

2. Запустите приложение в режиме разработки:
   ```
   npm run dev
   ```

## Структура базы данных

Схема базы данных находится в `shared/schema.ts`. Миграционные скрипты в папке `migrations`.

### Миграция базы данных

Для запуска миграции базы данных используйте:
```
node migrations/run.js
```

### Загрузка демо-данных

Для заполнения базы данных демо-данными:
```
node migrations/seed.js
```
